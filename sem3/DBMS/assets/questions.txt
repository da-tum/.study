DBMS Mid-Term Practice Set (ETCCMS304)
Mock paper drill (1 hour, 20 marks): pick any two questions from Section A and one OR-pair from Section B, then attempt one question of that pair.
Instructions: All questions are mandatory unless an OR choice is given. Justify every classification you make (keys, normal forms, model choice).
Section A (5 marks each)
Q1. [CO-1] [L-3] · 5 Marks
A public library stores its catalogue in a Hierarchical data model: Library → Category → Book, where every book sits under exactly one category.
The library now wants a book to appear under several categories at once (for example, Data Science and Statistics), and each category has its own curator.
1.	Explain whether the Hierarchical model can represent this requirement without duplicating book records.
2.	Suggest a better model for this scenario and compare how both models would structure the Book–Category data.
Q2. [CO-1] [L-3] · 5 Marks
A university uses a Network data model in which STUDENT and COURSE records are linked through owner–member sets.
1.	Explain how the Network model handles the many-to-many link between students and courses.
2.	The university plans to migrate to the Relational model. Compare how each model represents the enrolment data and state two advantages of the migration.
Q3. [CO-1] [L-2] · 5 Marks
The DBA moves the ORDERS table to faster SSD storage and adds a B+ tree index on Order_Date. No application program or user query had to be changed.
1.	Identify the type of data independence shown here and the two levels of the Three-Level Architecture involved.
2.	Explain the role of the mapping between those two levels.
Q4. [CO-1] [L-2] · 5 Marks
A new column Email is added to the STUDENT table in the conceptual schema. The fee-department view, which shows only Roll_No, Name and Fee_Status, keeps working unchanged.
1.	Name the type of data independence and the levels involved.
2.	Explain why this type of independence is harder to achieve than the other type.
Q5. [CO-1] [L-2] · 5 Marks
A mapping company stores city maps in which each map contains regions, each region contains roads, and each road is a list of coordinate points.
1.	Would you recommend a Relational or an Object-Oriented database? Justify by contrasting how each model represents this nested data.
2.	Name one situation where the Relational model would still be the better choice.

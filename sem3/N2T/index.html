Curriculum Roadmap & Blueprint

Project 01

Boolean Logic & Elementary Gates

Implementation of 15 elementary logic gates using strictly Nand primitives. Master truth table synthesis and multiplexer logic.

Not / And / Or / Xor Mux / DMux 16-Bit Multiway Mux8Way16
Ready for Notes
Project 02

Boolean Arithmetic & The ALU

Combinational arithmetic chips: Half Adders, Full Adders, 16-bit Incrementers, and the complete 16-bit Hack Arithmetic Logic Unit with status flags.

HalfAdder FullAdder Add16 ALU (zx, nx, zy, ny, f, no)
Ready for Notes
Project 03

Sequential Logic & Memory

Clocked storage elements. Transition from combinational to sequential circuits using D-Flip-Flops to build 16-bit Registers, RAM banks, and the Program Counter.

DFF & Bit Register RAM8 to RAM16K Program Counter (PC) Clock Cycles
Ready for Notes
Project 04

Machine Language (Hack Assembly)

Low-level binary code and mnemonic assembly specifications. Memory-mapped I/O, screen graphics manipulation, and keyboard polling loops.

A-Instruction (@val) C-Instruction (dest=comp;jump) SCREEN Memory Map KBD Ingestion
Ready for Notes
Project 05

Computer Architecture & CPU

Integrating CPU datapath, Instruction decode logic, Program Counter flow, and dual memory blocks (Instruction ROM32K & Data RAM16K) into the Hack Computer.

CPU.hdl Datapath Memory.hdl Computer.hdl Fetch-Decode-Execute
Ready for Notes
Project 06

The Assembler & Software Layer

Translating human-readable Hack assembly mnemonics into 16-bit binary machine instructions. Symbol resolution tables and label address calculation.

Lexer & Parser Symbol Table Code Generator Hack Binary (.hack)
Ready for Notes

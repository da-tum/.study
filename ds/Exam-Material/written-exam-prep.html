📐 Unit 1: Foundations & Searching Mechanics

A B.Tech CSE foundation detailing Big-O notations, recursion stacks, and search spacing.

1. Linear vs. Non-Linear Structures

Linear structures (Arrays, Stacks, Queues, Linked Lists) organize nodes sequentially. Non-linear structures (Trees, Graphs) arrange nodes hierarchically or as interconnected vertices.

2. Recursion Call Stacks & Tower of Hanoi

Recursion allocates temporary frame scopes inside the system's LIFO Call Stack. For the Tower of Hanoi ($N=3$ disks), moving from source rod $A$ to destination $C$ requires exactly $2^3 - 1 = 7$ sequential moves:

Step 1: Move disk 1 from A -> C
Step 2: Move disk 2 from A -> B
Step 3: Move disk 1 from C -> B
Step 4: Move disk 3 from A -> C
Step 5: Move disk 1 from B -> A
Step 6: Move disk 2 from B -> C
Step 7: Move disk 1 from A -> C

🔗 Unit 2: Linear Data Structures & Pointer Allocations

Details the memory representation of continuous arrays and pointer adjustments in singly, doubly, and circular linked lists.

1. Arrays vs. Linked List Memory Cost

Arrays allocate memory contiguously, allowing direct index access in $\Theta(1)$ time, but insertion requires shifting $O(n)$ elements. Linked Lists scatter nodes Dynamically in heap memory, using next pointers which consumes extra storage, but insertion at the head is extremely fast taking only $\Theta(1)$ time.

2. Singly vs. Doubly vs. Circular Lists

List Paradigm Pointer Structure Search Time Optimal Use Case
Singly Linked List Data + Next Pointer Only $O(n)$ Sequential Simple forward memory buffers
Doubly Linked List Data + Prev + Next Pointers $O(n)$ Bidirectional Browser back/forward histories
Circular Linked List Last next points to head $O(n)$ Cyclic loop Round-Robin CPU process scheduling

🗄️ Unit 3: Stack (LIFO) & Queue (FIFO) Operations

Analyzes basic stack boundaries (overflow/underflow) and wrap-around logic of Circular Queues.

1. Stack Boundaries

Stacks operate strictly at the `top`. Stack Overflow occurs when pushing to a full array: top == MAX - 1. Stack Underflow occurs when popping from an empty stack: top == -1.

2. Circular Queue Modulo Arithmetic

To avoid memory slot wastage in linear queues, circular queues wrap the rear and front pointers around the array boundaries using modulo arithmetic:

Enqueue: rear = (rear + 1) % MAX_SIZE
Dequeue: front = (front + 1) % MAX_SIZE
Full Condition: (rear + 1) % MAX_SIZE == front
Empty Condition: front == -1

🌳 Unit 4: Trees, Graph Traversals & Hash Collisions

1. AVL Balances & Rotations

An AVL Tree maintains balance by ensuring that the balance factor ($BF$) of every node satisfies $|BF| \le 1$. If $BF > 1$ (left heavy) or $BF < -1$ (right heavy), balancing rotations (LL, RR, LR, RL) are triggered.

❓ Q1: Array vs. Linked List on basis of memory and insertions.

Correct Answer:

  • Memory Allocation: Arrays use contiguous, static allocation determined at compile-time. Elements are stored adjacent to each other. Linked Lists use non-contiguous, dynamic allocation at runtime; nodes are scattered in heap memory, linked via address pointers.
  • Insertion Operation: Arrays require shifting elements sequentially, costing $O(n)$ worst-case. Singly Linked Lists insert at the beginning in $O(1)$ time by adjusting the head pointer, without shifting any elements.

❓ Q2: Find Time Complexity: i = 1; while i <= n: i = i * 3.

Correct Answer:

In each step, $i$ is multiplied by 3. Its value grows exponentially: $1, 3, 9, 27, \dots, 3^k$. The loop terminates when $3^k \ge n \Rightarrow k \ge \log_3 n$. Thus, the exact Time Complexity is $O(\log n)$ (Logarithmic).

❓ Q3: AVL Balance Factor and Rotations.

Correct Answer:

The Balance Factor ($BF$) of a node is calculated as: BF = Height(Left Subtree) - Height(Right Subtree).

For an AVL tree to remain balanced, the balance factor of every node must be $-1$, $0$, or $+1$. If $|BF| > 1$, four types of rotations restore balance:

  • LL Case: Single Right Rotation (when key inserted in left of left).
  • RR Case: Single Left Rotation (when key inserted in right of right).
  • LR Case: Left Rotation on left child, then Right Rotation on parent (when key inserted in right of left).
  • RL Case: Right Rotation on right child, then Left Rotation on parent (when key inserted in left of right).

❓ Q4: Compare Prime and Kruskal's MST Algorithms.

Correct Answer:

  • Prim's Algorithm: Grows the Minimum Spanning Tree from a single starting vertex, adding the cheapest connected edge at each step. Better for dense graphs. Time complexity: $O(E \log V)$.
  • Kruskal's Algorithm: Sorts all edges in ascending order of weight and adds them one-by-one, using Union-Find to avoid cycles. Better for sparse graphs. Time complexity: $O(E \log E)$ or $O(E \log V)$.

Unit 1: Fundamentals, Complexity & searching
Q1. Define Data Structure. Differentiate between linear and non-linear data structures. 2 Marks
A data structure is a systematic way of organizing and storing data in a computer so that it can be accessed and modified efficiently.
  • Linear DS: Elements are arranged sequentially (e.g., Arrays, Stacks, Queues, Linked Lists).
  • Non-Linear DS: Elements are organized hierarchically or in interconnected patterns (e.g., Trees, Graphs).
Q2. Define Time Complexity and Space Complexity with examples. 2 Marks
  • Time Complexity: Measures the amount of time taken by an algorithm to execute as a function of the input size $n$. Example: A single loop running from $0$ to $n-1$ has time complexity $O(n)$.
  • Space Complexity: Measures the amount of memory/space used by an algorithm during execution. Example: If only a constant number of helper variables are used, the space complexity is $O(1)$.
Q3. Differentiate between Big-O, Omega, and Theta notations. 2 Marks
  • Big-O ($O$): Represents the asymptotic upper bound (worst-case scenario).
  • Omega ($\Omega$): Represents the asymptotic lower bound (best-case scenario).
  • Theta ($\Theta$): Represents the exact bound where the running time is both upper and lower bounded (average-case scenario).
Q4. Arrange the following complexities in increasing order: $O(n^3)$, $O(\log n)$, $O(1)$, $O(n)$, $O(n \log n)$, $O(n^2)$, $O(2^n)$. 2 Marks
The correct increasing order (fastest to slowest) is: $$O(1) < O(\log n) < O(n) < O(n \log n) < O(n^2) < O(n^3) < O(2^n)$$
Q5. Why does Binary Search require sorted data? 2 Marks
Binary Search eliminates half of the search space in each step based on a comparison with the middle element. This elimination is mathematically guaranteed only if the array is sorted, as all elements to the left of the middle will be smaller and those to the right will be larger.
Q6. What is recursion? State the importance of the base case. 2 Marks
Recursion is a programming technique where a function calls itself directly or indirectly to solve a smaller subproblem. The base case is the condition that terminates the recursive calls. Without a base case, recursion leads to infinite execution and a stack overflow error.
Unit 2: Linked Lists, Stacks & Queues
Q7. What is Stack Overflow and Stack Underflow? State conditions. 2 Marks
  • Stack Overflow: Attempting to PUSH an element onto a stack that is already full. Condition: top == MAX_SIZE - 1.
  • Stack Underflow: Attempting to POP an element from an empty stack. Condition: top == -1.
Q8. Differentiate between Singly, Doubly, and Circular Linked Lists. 2 Marks
  • Singly: Nodes have data and a single next pointer pointing forward.
  • Doubly: Nodes have prev and next pointers allowing bidirectional traversal.
  • Circular: The next pointer of the last node points back to the head node, forming a closed ring.
Q9. Explain the Enqueue and Dequeue time complexities for Circular Queue. 2 Marks
Both enqueue (inserting rear element) and dequeue (deleting front element) take constant time $O(1)$ in a circular queue because elements are accessed directly via pointers without any shifting of slots.
Q10. What is a double-ended queue (Deque)? State its types. 2 Marks
A Deque is a queue that allows insertion and deletion of nodes at both the front and rear ends. Its two variants are:
  1. Input-Restricted Deque: Insertions allowed at one end only, deletions at both ends.
  2. Output-Restricted Deque: Deletions allowed at one end only, insertions at both ends.
Unit 3: Sorting & Hashing
Q11. Compare Bubble Sort and Selection Sort based on swapping overhead. 2 Marks
While both Bubble and Selection Sort have worst-case time complexities of $O(n^2)$, Selection Sort is much faster in terms of writes/swaps. Bubble Sort swaps adjacent elements repeatedly in every pass, requiring up to $O(n^2)$ swaps. Selection Sort swaps at most once per outer loop iteration, making at most $O(n)$ swaps.
Q12. What is stable sorting? Give examples of stable and unstable sorts. 2 Marks
A sorting algorithm is stable if it preserves the relative order of duplicate/equal elements in the sorted output.
  • Stable Sorts: Bubble Sort, Insertion Sort, Merge Sort.
  • Unstable Sorts: Selection Sort, Quick Sort, Heap Sort.
Q13. Define collision in hashing and list two collision resolution techniques. 2 Marks
A collision occurs when two distinct keys hash to the exact same index in a hash table. Resolutions:
  1. Chaining (Open Hashing): Stores keys mapping to the same index inside a linked list attached to the bucket.
  2. Linear Probing (Closed Hashing): Linearly scans the hash table for the next empty slot to store the collided key.
Unit 4: Trees, Graphs & Advanced Topics
Q14. Define balance factor ($BF$) of AVL tree and state its valid range. 2 Marks
The Balance Factor ($BF$) of a node is: $$BF = \text{Height}(\text{Left Subtree}) - \text{Height}(\text{Right Subtree})$$ For a binary tree to be a valid self-balancing AVL tree, the balance factor of every node must fall strictly in the range: $$BF \in \{-1, 0, +1\}$$
Q15. State the data structures used in BFS and DFS traversals. 2 Marks
  • BFS (Breadth First Search): Uses a Queue (FIFO) to explore level by level.
  • DFS (Depth First Search): Uses a Stack (LIFO) (or call stack via recursion) to explore deeply branch by branch.
Q16. What is a Min Heap and Max Heap? 2 Marks
A Heap is a complete binary tree:
  • Min Heap: The key of the parent node is always smaller than or equal to the keys of its children. The root contains the minimum element.
  • Max Heap: The key of the parent node is always greater than or equal to the keys of its children. The root contains the maximum element.

Q3. Merge Sort Program & Trace: 72, 18, 55, 9, 34, 81, 26, 47. 10 Marks

Complete Python Implementation:

def merge_sort(arr):
    if len(arr) > 1:
        mid = len(arr) // 2
        left = arr[:mid]
        right = arr[mid:]

        merge_sort(left)
        merge_sort(right)

        i = j = k = 0
        while i < len(left) and j < len(right):
            if left[i] < right[j]:
                arr[k] = left[i]
                i += 1
            else:
                arr[k] = right[j]
                j += 1
            k += 1

        while i < len(left):
            arr[k] = left[i]
            i += 1
            k += 1

        while j < len(right):
            arr[k] = right[j]
            j += 1
            k += 1

Q5. Implement a Circular Queue using arrays in C/Python. Explain Enqueue/Dequeue algorithms. 10 Marks

Python implementation:

class CircularQueue:
    def __init__(self, size):
        self.size = size
        self.queue = [None] * size
        self.front = self.rear = -1

    def enqueue(self, data):
        if (self.rear + 1) % self.size == self.front:
            print("Queue is Full (Overflow!)")
            return
        elif self.front == -1: # First element insert
            self.front = self.rear = 0
        else:
            self.rear = (self.rear + 1) % self.size
        self.queue[self.rear] = data

    def dequeue(self):
        if self.front == -1:
            print("Queue is Empty (Underflow!)")
            return None
        temp = self.queue[self.front]
        if self.front == self.rear: # Only one element in queue
            self.front = self.rear = -1
        else:
            self.front = (self.front + 1) % self.size
        return temp

Overcoming Linear Queue wastage:

In a linear queue, when elements are dequeued, the empty memory slots at the front are wasted because the rear pointer can only increment forward. In a circular queue, the modulo arithmetic operator % allows pointers to wrap around back to index 0 when they reach the end index MAX_SIZE-1, thereby making full utilization of the array capacity.

Q7. Complexity Analysis: Analyze loop structures sequential O(n), logarithmic O(log n), quadratic O(n²). 8 Marks
  1. Snippet (a): 
    for i in range(n):
    print(i)
    Complexity: $O(n)$ linear complexity. The loop iterates exactly $n$ times, performing constant-time print operations in each step.
  2. Snippet (b): 
    i = 1
while i < n:
    i = i * 3
    Complexity: $O(\log n)$ logarithmic complexity. The variable $i$ triples in value with every iteration: $1, 3, 9, 27, \dots, 3^k$. The loop exits when $3^k \ge n \Rightarrow k = \log_3 n$.
  3. Snippet (c): 
    for i in range(n):
    for j in range(n):
        print(i, j)
    Complexity: $O(n^2)$ quadratic complexity. The outer loop runs $n$ times. For each iteration, the inner loop also runs $n$ times. Total steps = $n \times n = n^2$.

# Contributing to the Study Portal

Thank you for choosing to contribute to the Academic Study Portal!

## Code of Conduct

Please maintain a collaborative, respectful, and professional environment in all interactions.

## PR Process

1. Fork the repository and create your branch from `main`.
2. Make your edits ensuring that all interactive elements are responsive and responsive layouts are verified on mobile viewports.
3. Ensure no local secrets or hardcoded credentials are included.
4. Format all HTML, CSS, and JS. Keep CSS variables scoped under `:root`.
5. Open your pull request with a descriptive title using [Conventional Commits](https://www.conventionalcommits.org/) format (e.g. `feat: add search to ds portal`).

## Linting & Code Style

- Keep code readable, modular, and performant.
- Do not use inline script execution loops that block the main thread. Always defer math rendering or heavy computations.

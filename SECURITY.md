# Security Policy

## Supported Versions

Only the latest active release of this study portal is supported for security patches.

| Version | Supported          |
| ------- | ------------------ |
| 1.0.x   | :white_check_mark: |
| < 1.0   | :x:                |

## Reporting a Vulnerability

If you discover a security vulnerability, please report it via the contact methods specified in our project proposal or repository owners page. Do not open public issues for security vulnerabilities.

We aim to acknowledge and investigate all reports within 48 hours and provide a remediation plan within 5 business days.
